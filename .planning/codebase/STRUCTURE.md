## Directory Purposes

**`inaproc-ds/outputs/`:**
- Purpose: Raw source dataset of Indonesian 2026 government procurement records
- Contains: ~123 partitioned shards in four file formats per partition
- Key files: `year-2026.part-00001.jsonl` through `year-2026.part-00123.jsonl`
- Note: gitignored; must be downloaded separately (~3.2 GB)

**`dashboard/src/`:**
- Purpose: All Svelte application source code
- Contains: Three files — entry point, page component, chart component
- Key files: `App.svelte`, `BarChart.svelte`, `main.js`

**`dashboard/public/data/`:**
- Purpose: Static JSON data files served directly to the browser
- Contains: Two pre-aggregated JSON files generated by `prepare-data.py`
- Key files: `lembaga-totals.json` (top-30 institutions), `summary-stats.json` (dataset totals)
- Note: Committed to git intentionally so dashboard works without the raw dataset

**`dashboard/scripts/`:**
- Purpose: Offline data processing — run once by developer, not at runtime
- Contains: `prepare-data.py` — Python stdlib-only script
- Key files: `prepare-data.py`

**`dashboard/dist/`:**
- Purpose: Vite build output; the deployable static site
- Contains: Bundled JS/CSS assets, copied `public/` files, `index.html`
- Generated: Yes
- Committed: No (gitignored)

**`.planning/`:**
- Purpose: GSD planning artifacts — codebase maps, research, phase plans
- Contains: `codebase/` (this directory), `research/questions.md`
- Generated: Yes (by GSD commands)
- Committed: Yes (planning is part of the project)

**`antivibe-explain/`:**
- Purpose: AI-generated explanation documents (generated artifact)
- Contains: Markdown files like `dashboard-2026-05-12.md`
- Generated: Yes
- Committed: No (gitignored)

## Key File Locations

**Entry Points:**
- `dashboard/index.html`: HTML shell; references `src/main.js`
- `dashboard/src/main.js`: Mounts Svelte `App` into `#app`

**Configuration:**
- `dashboard/vite.config.js`: Vite build config with Svelte plugin
- `dashboard/package.json`: npm scripts (`dev`, `build`, `preview`, `prepare-data`)

**Core Logic:**
- `dashboard/src/App.svelte`: Page layout, fetch, IntersectionObserver scroll logic
- `dashboard/src/BarChart.svelte`: D3 scales, SVG rendering, step-driven visual transitions
- `dashboard/scripts/prepare-data.py`: Dataset aggregation; reads shards, writes public JSON

**Static Data:**
- `dashboard/public/data/lembaga-totals.json`: Top-30 institution aggregates (runtime data)
- `dashboard/public/data/summary-stats.json`: Dataset-wide totals (runtime data)

**Documentation:**
- `SPEC.md`: Product spec, storyline, audience, tone
- `CLAUDE.md`: Dataset field reference and query patterns for AI agents

## Naming Conventions

**Files:**
- Svelte components: PascalCase (e.g., `App.svelte`, `BarChart.svelte`)
- JS entry: camelCase (e.g., `main.js`)
- Python scripts: kebab-case (e.g., `prepare-data.py`)
- Data files: kebab-case (e.g., `lembaga-totals.json`, `summary-stats.json`)
- Dataset shards: `year-2026.part-NNNNN[_suffix].ext`

**Directories:**
- Lowercase with hyphens for multi-word (e.g., `node_modules`, `antivibe-explain`)
- Hidden dot-directories for tooling/planning (e.g., `.planning/`)

## Where to Add New Code

**New Svelte page section:**
- Primary code: `dashboard/src/App.svelte` (add a new `<section>` block)
- If complex, extract to: `dashboard/src/NewSection.svelte`

**New chart or visualization component:**
- Implementation: `dashboard/src/NewChart.svelte`
- Import into: `dashboard/src/App.svelte`

**New aggregated data file (e.g., word frequency, per-region breakdown):**
- Add computation to: `dashboard/scripts/prepare-data.py`
- Output target: `dashboard/public/data/new-data.json`
- Fetch in: `dashboard/src/App.svelte` alongside existing fetches

**New Python data prep script (separate concern):**
- Location: `dashboard/scripts/new-script.py`
- Add npm script to: `dashboard/package.json`

**Planning artifacts:**
- Phase plans: `.planning/` (managed by GSD commands)
- Research notes: `.planning/research/`

## Special Directories

**`dashboard/node_modules/`:**
- Purpose: npm package dependencies (D3 v7, Svelte 5, Vite 5, plugin)
- Generated: Yes (via `npm install`)
- Committed: No

**`dashboard/dist/`:**
- Purpose: Production build output — deploy this directory to a static host
- Generated: Yes (via `npm run build`)
- Committed: No

**`inaproc-ds/outputs/`:**
- Purpose: Source dataset archive (too large for git)
- Generated: No (downloaded from external URL documented in `CLAUDE.md`)
- Committed: No (gitignored)

**`dashboard/public/data/`:**
- Purpose: Runtime JSON; copied verbatim into `dist/` by Vite
- Generated: Yes (by `prepare-data.py`)
- Committed: Yes (intentionally — allows dashboard to run without raw dataset)
