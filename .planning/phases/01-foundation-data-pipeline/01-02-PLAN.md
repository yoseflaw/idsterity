## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User click events → JavaScript handlers | The lang-toggle button receives untrusted click events; handler mutates application state |
| scrollama → DOM (observer side-effects) | scrollama installs IntersectionObserver; if not torn down, observers accumulate and corrupt state |
| Window resize events → scrollama recalculation | Browser-fired event triggers scroller.resize() — could be exploited via rapid resize but no security impact |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02-01 | Tampering / XSS | Toggle button rendering `{t[lang].toggleLabel}` | accept | The toggleLabel value is hard-coded in `src/i18n.js` (static literal "English" / "Indonesia") and rendered through Svelte's escaping. No path for user input to reach this string. Low risk. |
| T-01-02-02 | Denial of service | scrollama observer leak on HMR | mitigate | onDestroy / $effect cleanup explicitly calls `scroller.destroy()` to remove observers. Acceptance criteria require this code path. Verify command checks for `scroller.destroy()` literal. |
| T-01-02-03 | Tampering | scrollama version drift introducing breaking changes | mitigate | `package-lock.json` (from Plan 01 Task 1) pins exact resolved scrollama version. Manual smoke check (Task 3 check 4) validates fire-once-per-step still works after each `npm install`. |
| T-01-02-04 | Information disclosure | window.scrollY exposed to event handler | accept | Reading `window.scrollY` is a normal browser API; no sensitive information. Required for the FOUND-03 scroll-preserving toggle behavior. |
| T-01-02-05 | Repudiation | No logging of language toggle | accept | UI-SPEC analytics is a deferred v2 item per STATE.md "Analytics event tracking | Deferred". Phase 1 does not record toggle usage. |
