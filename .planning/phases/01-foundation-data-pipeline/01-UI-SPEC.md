# Phase 1 — UI Design Contract

> Visual and interaction contract for Phase 1: Foundation & Data Pipeline.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — pure CSS custom properties |
| Preset | not applicable |
| Component library | none |
| Icon library | none — Unicode arrows and inline SVG only |
| Font | Libre Baskerville (headlines/display), Source Serif 4 (body/labels), JetBrains Mono (eyebrow/monospace) |

**Rationale:** The existing POC already establishes a working token system in `:global(:root)`. Phase 1 formalizes and extends it — no design system library is added. This is consistent with REQUIREMENTS.md (FOUND-04: Pudding.cool-style via CSS custom properties) and the project's explicit "no Tailwind" constraint from CLAUDE.md.

**Self-hosting requirement (FOUND-06):** Google Fonts CDN links in `index.html` must be replaced with `@fontsource/*` npm packages imported in `main.js`. Phase 1 ships this change.

**Primary visual anchor:** hero h1 + hero stat box (Display type, top of viewport).

## Spacing Scale

Declared values (multiples of 4):

| Token | CSS Variable | Value | Usage |
|-------|-------------|-------|-------|
| xs | `--space-xs` | 4px | Icon gaps, inline padding, pip spacing |
| sm | `--space-sm` | 8px | Compact element spacing, label gaps |
| md | `--space-md` | 16px | Default element spacing, card inner padding base |
| lg | `--space-lg` | 24px | Card padding, step-card internal spacing |
| xl | `--space-xl` | 32px | Chart margin, section inner padding |
| 2xl | `--space-2xl` | 48px | Section vertical rhythm |
| 3xl | `--space-3xl` | 64px | Major section breaks |
| page | `--space-page` | 96px | Hero top/bottom padding, closing section |

**Pre-populated from:** Existing App.svelte spacing values (2rem=32px, 1.5rem=24px, 6rem=96px observed).

Exceptions:
- Touch targets: language toggle button minimum 44×44px (MOB-03 — enforced from Phase 2 onward, but the token is defined here so Phase 2 can inherit it)
- Step pip indicator: 20px inactive / 32px active (existing POC values — kept as-is, within the 4-point grid)
- Scroll cue bob animation uses 7px translate — this is an animation offset, not a spacing token, so it is exempt from the 4-point grid constraint

## Typography

**Fonts (all three must be self-hosted via `@fontsource/*` after Phase 1):**
- `Libre Baskerville` — serif, 400 / 700 / 400 italic — headlines and display numbers
- `Source Serif 4` — serif, 400 only, optical size 8–60pt — body and labels
- `JetBrains Mono` — monospace, 400 only — eyebrow, axis labels, source lines

**Typography scale (4 sizes, 2 weights):**

| Role | Font | Size | Weight | Line Height | CSS Variable | Usage |
|------|------|------|--------|-------------|-------------|-------|
| Eyebrow | JetBrains Mono | 11px (0.7rem) | 400 | 1.5 | `--text-eyebrow` | Section labels, step counters, axis ticks, source lines |
| Body | Source Serif 4 | 16px (1rem) | 400 | 1.78 | `--text-body` | Prose paragraphs, step card body, callout text, opening paragraph copy |
| Heading | Libre Baskerville | 23px (1.45rem) | 700 | 1.2 | `--text-heading` | Step card h3, section headings (h2) |
| Display | Libre Baskerville | fluid clamp(2.2rem, 6vw, 5.5rem) | 700 | 1.08 | `--text-display` | Hero h1, hero stat number, callout figures |

**Notes on collapsed roles:**
- Lead (19px) is removed. Opening paragraph copy renders at Body size (16px, weight 400). The narrative context and section positioning provide sufficient visual distinction without a separate size.
- Stat is merged into Display. Hero h1 and large callout figures share the same fluid clamp `clamp(2.2rem, 6vw, 5.5rem)`. The minimum end (2.2rem) keeps stat numbers readable on small screens; the maximum end (5.5rem) gives the hero h1 full impact on large screens. No separate fluid range is needed.

**Pre-populated from:** Existing App.svelte and BarChart.svelte — values are extracted from the POC code and promoted to named tokens.

Letter-spacing conventions:
- Eyebrow / JetBrains Mono labels: `letter-spacing: 0.15–0.2em` (retain existing values)
- Headings: `letter-spacing: -0.02em` (retain existing)
- Body: default (no letter-spacing)

Chart-specific typography (within SVG — not tokenized as CSS vars, declared here for D3 usage):
- Axis tick labels: 10px, JetBrains Mono, `rgba(237,232,220,0.3)`
- Institution name labels: 12px, Source Serif 4, `rgba(237,232,220,0.82)`
- Value labels: 10px, JetBrains Mono, `rgba(201,168,76,0.6)`
- Legend labels: 10px, Source Serif 4, `rgba(237,232,220,0.45)`

## Copywriting Contract

Phase 1 does not introduce final story copy — that is Phase 2 (S1–S6 sections). Phase 1 establishes skeleton infrastructure with placeholder copy and the i18n store. The following copy elements are the **infrastructure-level strings** Phase 1 must define in `i18n/id.json` and `i18n/en.json`.

| Element | Indonesian (id) | English (en) |
|---------|-----------------|--------------|
| Language toggle label | `English` | `Indonesia` |
| Scroll cue | `gulir untuk menjelajahi ↓` | `scroll to explore ↓` |
| Loading state | `memuat data…` | `loading data…` |
| Eyebrow label | `idsterity · Analisis Pengadaan Indonesia 2026` | `idsterity · Indonesia 2026 Procurement Analysis` |
| Hero h1 line 1 | `Ke mana perginya` | `Where did the` |
| Hero h1 line 2 | `uang rakyat?` | `people's money go?` |
| Skeleton section placeholder | `[bagian sedang disiapkan]` | `[section in preparation]` |
| Section stub step counter pattern | `{N} / {total}` | `{N} / {total}` |

**Primary CTA (Phase 1 scope):** "gulir untuk menjelajahi ↓" / "scroll to explore ↓" — this is the only call to action in Phase 1's skeleton. No button CTAs exist in Phase 1 beyond the language toggle.

**Empty state (data not yet loaded):**
- Heading: none — use loading-pulse animation on the stat number (`Rp — T`)
- Body: "memuat data…" / "loading data…"
- This is the only loading state Phase 1 must handle — section stubs do not fetch data

**Error state:** Phase 1 does not implement error handling for fetch failures (that is a Phase 4 polish item). The skeleton page renders static stub content that does not depend on fetched data. Exception: if `lembaga-totals.json` or `summary-stats.json` fetch fails, the POC's existing silent failure behavior is acceptable for Phase 1 (it shows the loading state indefinitely). Phase 4 will add visible error copy.

**Destructive actions in Phase 1:** None. No destructive actions exist in Phase 1 scope.

## Interaction Contracts

### Language Toggle Button

- **Placement:** Fixed position, top-right corner, `position: fixed; top: 16px; right: 16px; z-index: 100`
- **Size:** Minimum 44×44px touch target (MOB-03 — enforced now on the one interactive element Phase 1 ships)
- **Visual:** Pill shape, 1px solid border using `var(--border)`, background `var(--bg-card)`, text in JetBrains Mono 11px
- **Active language indicator:** Current language label rendered with `font-weight: 700` and `color: var(--gold)`. Inactive language dimmed to `var(--muted)`.
- **Label content:** Two-state text — when ID is active, button reads "English"; when EN is active, button reads "Indonesia". (User reads the target language, not the current one — standard convention.)
- **On click:** `setLocale()` call switches language. Scroll position preserved via `window.scrollY` read before and `requestAnimationFrame` restore after re-render.
- **Transition:** 150ms crossfade on the label text (`transition: opacity 0.15s ease`)
- **No URL change.** Language preference persists to localStorage under key `idsterity-lang`.

### Scrollama Skeleton

Phase 1 wires up Scrollama 3.2 against section stubs. Each section stub:
- Has a `data-section="N"` attribute for top-level section tracking
- Has at least one `data-step="0"` element inside scrolly sections
- Fires `onStepEnter` with `offset: 0.5` (50% viewport threshold — Pudding standard)
- Step counter `activeSection` lives in `App.svelte` as `$state(0)`
- Step pip indicator renders at bottom of sticky panel: inactive pips at `var(--border)` fill, active at `var(--gold)` fill

### Step Pip Indicator

- 4 pips (matching 4 scroll steps in the existing POC — Phase 1 inherits this, later phases may extend)
- Inactive: 20×3px rectangle, `border-radius: 2px`, fill `var(--border)`
- Active: 32×3px rectangle, fill `var(--gold)`, transition `width 0.4s ease, background 0.4s ease`
- Gap between pips: 8px (`--space-sm`)
- Visible on desktop only — hide below 800px breakpoint (matches existing responsive rule)
- Pip container must carry `aria-hidden="true"` — the indicator is decorative and non-interactive; screen readers should not announce it

### Scroll Cue Animation

- "gulir untuk menjelajahi ↓" link below hero stat box
- `animation: bob 2.2s ease-in-out infinite` — 7px vertical translate at 50% keyframe
- Color `var(--muted)`, hover transitions to `var(--gold)` in 0.2s
- Hidden once user scrolls past hero (Phase 2 can implement this; Phase 1 just keeps it always visible)

### Loading Pulse

- Applied to hero stat box when data fetch is pending
- `animation: pulse 1.8s ease-in-out infinite`, opacity alternates 0.5 → 0.9
- Removed once `stats` state is populated

## Font Self-Hosting Migration (FOUND-06)

Phase 1 replaces the three `<link>` tags in `index.html` with `@fontsource` imports in `main.js`:

```js
// dashboard/src/main.js — additions
import '@fontsource/libre-baskerville/400.css';
import '@fontsource/libre-baskerville/700.css';
import '@fontsource/libre-baskerville/400-italic.css';
import '@fontsource/source-serif-4/400.css';
import '@fontsource/jetbrains-mono/400.css';
```

CSS font declarations must include `font-display: swap` (the `@fontsource` packages set this by default).

Fallback stacks (to declare in `:root` or body):
- Libre Baskerville: `'Libre Baskerville', Georgia, 'Times New Roman', serif`
- Source Serif 4: `'Source Serif 4', Georgia, serif`
- JetBrains Mono: `'JetBrains Mono', 'Courier New', monospace`
