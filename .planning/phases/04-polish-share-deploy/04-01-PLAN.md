| index.html → LinkedIn scraper | LinkedIn reads og:image as an absolute HTTPS URL; no user input crosses this boundary |
| browser → og-image.jpg | Static JPEG served by Apache directly; no processing |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-04-01 | Information Disclosure | og:image absolute URL | accept | URL is intentionally public; reveals deploy path (yosef.id/sterity/) which is already public |
| T-04-02 | Tampering | og-image.jpg static file | accept | Static asset served by Apache; no user-writable path; low-value target (no PII) |
| T-04-03 | Spoofing | og:url hardcoded value | accept | Hardcoded to canonical URL per D-07; no user input; cannot be spoofed at meta-tag level |
</threat_model>
