## Phase Goal

**As a** visitor, **I want to** see honest stacked-bar segments that reflect actual pagu amounts per AI-label tier (low/med/high) on the institutions chart, **so that I** trust the visual encoding instead of seeing inflated proxies.

<objective>
Extend `prepare-data.py` so the S5+S6 InstitutionsChart in Plan 05 can render accurate stacked bar segments. PATTERNS.md §Data Shape Notes flagged that `lembaga-totals.json` currently exposes `flaggedPagu` (total flagged), `highCount`, `medCount` but no per-label pagu totals. Without `lowPagu`, `medPagu`, `highPagu` per institution, the stacked bar would have to estimate segment widths from counts — visually lossy and dishonest. Also apply Phase 1 code review item CR-03: guard `label_pagu['unflagged']` and `label_counts['unflagged']` against negative values and emit a WARNING when the input shards are inconsistent.

Purpose: Provide honest data shape for the S5/S6 chart in Plan 05 and close CR-03 from Phase 1 review.
Output: Patched `prepare-data.py`, regenerated `lembaga-totals.json` (each record has `lowPagu`, `medPagu`, `highPagu` integer fields), regenerated `summary-stats.json` (non-negative unflagged values, WARNING printed if inconsistency detected).
</objective>
