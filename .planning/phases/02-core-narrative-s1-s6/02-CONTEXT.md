# Phase 02: Core Narrative (S1–S6) - Context

**Gathered:** 2026-05-13
**Status:** Ready for planning

<domain>
## Phase Boundary

Phase 2 builds the 6 scroll sections that form the opening narrative arc. A visitor can scroll through: an ironic government-promise opener (S1), APBN deficit visualization (S2), GDP government consumption visualization (S3), procurement dataset overview with AI-label breakdown (S4), top institutions stacked bar chart (S5), and the high-inappropriate re-rank (S6) — all in both languages on any screen 375px+.

Phase 2 does NOT build S7 (anchor numbers), S8 (word cloud), or S9 (explore table) — those are Phase 3.

</domain>

<decisions>
## Implementation Decisions

### Section Architecture
- **D-01:** Use **multiple scrolly sections** — each narrative chapter gets its own scrolly block with its own sticky panel. S1: quote-display sticky. S2: deficit chart sticky. S3: GDP chart sticky. S4: no sticky (full-width stats block). S5+S6: shared stacked bar sticky.
- **D-02:** S5 and S6 share **one scrolly section** with one sticky panel. When the user scrolls from S5 steps into S6 steps, the stacked bar chart re-sorts in place with a **D3 animated transition** — institutions re-rank by high-inappropriate spending only. No new sticky instance for S6.

### S1 Hook
- **D-03:** S1 shows **narrative copy with news article links** — no named officials quoted, no explicit attribution to individuals. The framing establishes the government's fiscal efficiency promises contextually through news headlines/links.
- **D-04:** S1 is a **single scroll step**. The sticky panel displays the opening line ("Follow the… Where is the money?" / "Ikuti jejaknya… Ke mana perginya uang rakyat?") as large display text. The step card contains a list of 3–5 news links.

### Narrative Copy
- **D-05:** Claude **drafts all bilingual copy** (Indonesian primary, English secondary) during implementation. User reviews and refines after the build. Copy is committed as part of the implementation.
- **D-06:** Tone for S2/S3 narrative framing: **dry irony — let the numbers speak**. Minimal editorial commentary. Copy sets context and asks the question; the chart delivers the punchline. Example register: "The government promised fiscal efficiency. Government consumption grew 10.93% in Q2 2025."
- **D-07:** S4 safe harbour disclaimer: **small footnote below the stats**. Small-text JetBrains Mono: "Labels generated by AI model. For reference only." Honest without undermining the narrative.

### Chart Components
- **D-08:** Use **separate dedicated chart components** — `DeficitChart.svelte` (S2), `GDPChart.svelte` (S3), `InstitutionsChart.svelte` (S5+S6). Each component is purpose-built for its data shape. No conditional logic tangling.
- **D-09:** `BarChart.svelte` is **replaced by `InstitutionsChart.svelte`**. The old POC horizontal bar chart is deleted. `InstitutionsChart.svelte` handles the stacked bar with low/med/high segments and the animated re-sort for S6.
- **D-10:** S2 (APBN deficit) and S3 (GDP consumption) both use an **isometric coin stack** visual — each data point rendered as a stack of coins/cash (SVG illustration), with stack height mapping to the value. Consistent visual language across both macro sections. `DeficitChart.svelte` and `GDPChart.svelte` implement this custom SVG treatment.

### Claude's Discretion
- Number of scroll steps within each section (S2, S3, S5) — Claude picks based on narrative pacing.
- Isometric coin stack SVG implementation details — Claude builds the illustration.
- Exact wording of all bilingual copy keys in `i18n.js` — Claude drafts, user refines.
- How scrollama instances are managed per section (one global scroller vs. per-section instances).
- Fix CR-01, CR-02, CR-03, WR-05 from Phase 1 code review as part of this phase's implementation.

</decisions>

<code_context>
## Existing Code Insights

### Reusable Assets
- `App.svelte` CSS token system (`:global(:root)`) — all new sections use existing `--color-*`, `--space-*`, `--text-*` tokens. No new tokens should be added unless justified.
- `i18n.js` `t[lang].key` pattern — extend with S1–S6 keys following the same flat key structure.
- Scrollama instance in `App.svelte` — currently one scroller on `[data-step]`. Phase 2 extends to multiple scrolly sections; scrollama re-initialization or multiple instances needed per section.
- `$state(0)` / `$derived()` runes pattern — follow for any new reactive state per section.

### Established Patterns
- `data-step="N"` attributes on step cards → scrollama fires `onStepEnter({ index })` → updates `$state`.
- Sticky panel: `position: sticky; top: 0; height: 100vh` (left column on desktop, top on mobile).
- Step cards in right column: `display: flex; flex-direction: column; gap: var(--space-2xl)`.
- Mobile (≤ 600px): `flex-direction: column` — chart above steps, full width.
- All colors via `var(--name)` CSS tokens. No hardcoded hex.
- D3 named imports: `import { scaleBand, scaleLinear } from 'd3'`.

### Integration Points
- `constants.json` → `DeficitChart.svelte` + `GDPChart.svelte` (fetched once in `App.svelte`, passed as prop).
- `lembaga-totals.json` → `InstitutionsChart.svelte` (already fetched in `App.svelte`; pass as `data` prop with `step` for S5/S6 active step tracking).
- `summary-stats.json` → S4 stats block in `App.svelte`.
- Language state `lang` → prop-drilled to all three chart components.

</code_context>

<specifics>
## Specific Ideas

- **S2/S3 chart style:** Isometric coin stack — custom SVG illustration where each data bar is rendered as a stack of coins/cash icons. Stack height proportional to value. This is a visual signature, not a standard D3 chart.
- **S5→S6 transition:** D3 animated re-sort. When the user scrolls into S6 steps, institutions re-rank with smooth position transitions (D3 `transition().duration(600)`). The narrative framing in the step card bridges the two views.
- **S1 opener:** "Follow the… Where is the money?" / "Ikuti jejaknya… Ke mana perginya uang rakyat?" — display-size text in sticky panel. Step card lists news links with short descriptive anchor text.
