| Property | Value |

## Spacing Scale

All values inherited from Phase 1. No new spacing tokens.

| Token | CSS Variable | Value | Phase 2 Usage |
|-------|-------------|-------|---------------|
| xs | `--space-xs` | 4px | Icon gaps, pip spacing, inline padding in step cards |
| sm | `--space-sm` | 8px | Gap between news-link items in S1 step card, chart internal label gaps |
| md | `--space-md` | 16px | Horizontal padding within step cards, isometric chart internal padding, source link margin |
| lg | `--space-lg` | 24px | Step card padding, section heading margin-bottom, news-links top margin |
| xl | `--space-xl` | 32px | Sticky panel internal padding, chart margin from panel edge, S4 stats-grid gap |
| 2xl | `--space-2xl` | 48px | Vertical gap between sections (between S1, S2, S3…); S4 heading bottom margin |
| 3xl | `--space-3xl` | 64px | S4 stats-grid bottom margin to breakdown section |
| page | `--space-page` | 96px | S4 section vertical padding (top and bottom); S4 mobile overrides to `--space-2xl` top/`--space-lg` sides |

**Touch target exception (MOB-03):** All interactive elements — language toggle, news article links in S1, source attribution links in S2/S3 — must have a minimum 44×44px tap target. Links in step cards use `display: inline-block; min-height: 44px; padding: var(--space-sm) 0` to guarantee this without layout disruption.

**Exceptions beyond Phase 1:**
- S4 safe harbour disclaimer: `margin-top: var(--space-md); padding-top: var(--space-md)` — 16px margin and padding above the border-top divider line (non-structural, rhythm separator).
- Isometric coin stack: coin layer height = 8px stacked increments (2 × `--space-xs`) — internal SVG attribute, not a CSS spacing token.
- S6 transition label: `margin-top: var(--space-sm)` — 8px above the label in the step card.

**60/30/10 verification (Phase 2 extends same surfaces):**

**`--kabkota` / `--gold` proximity note:** `--kabkota` (#c4a04a) and `--gold` (#c9a84c) are visually proximate (~5 hex units apart). This proximity is intentional. The two tokens serve distinct roles at different opacities and rendered sizes: `--kabkota` is used exclusively for S5 district/city tier bar segments at full opacity as a data-encoding color, while `--gold` accent labels render at 0.6–0.85 opacity in SVG context at 10–11px. At rendered sizes, the opacity and size difference provides sufficient visual separation. No additional differentiation token is required.

## Section Layout Contracts

### Scrolly Section Structure (S1, S2, S3, S5+S6)

Each section uses the two-column layout established in Phase 1:

```
.scrolly[data-section="N"]
  └── .sticky-col   (60% width desktop / 100% stacked mobile)
        ├── .eyebrow  [JetBrains Mono 0.7rem, var(--gold), letter-spacing 0.2em, uppercase]
        ├── [chart component or display text block]
        └── .step-indicator (pip row — desktop only, aria-hidden)
              └── .pip × N  [20×3px, border-radius 2px; active pip: gold, 32px wide]
  └── .steps-col    (40% width desktop / 100% stacked mobile)
        └── .step[data-step="N"] × (N steps per section)
              [min-height: 100vh; display: flex; align-items: center; padding: 3rem 0]
              └── .step-card  [bg-card, border, border-radius 4px, padding 2rem 1.75rem, max-width 380px]
                    ├── .step-num   [JetBrains Mono 0.65rem, letter-spacing 0.15em, gold, opacity 0.8]
                    ├── h3          [Libre Baskerville 1.45rem, weight 700, line-height 1.2]
                    └── p           [Source Serif 4 0.95rem, weight 400, line-height 1.72, color --muted]
```

**Multiple scrolly instances (D-01):** Each of S1, S2, S3 gets its own `.scrolly` wrapper with `data-section` attribute. S5+S6 share one `.scrolly`. Each section's sticky panel tracks its own `$state` integer — `activeStepS1`, `activeStepS2`, `activeStepS3`, `activeStepS5` — via one Scrollama instance per section.

**Sticky panel height (desktop):** `height: 100dvh` (not `100vh`) — consistent with Phase 1 mobile chrome handling.

**Pip indicator:** Pip width 20px normal, 32px active. Pip height 3px. Color `var(--border)` normal, `var(--gold)` active. Transition: `background 0.4s ease, width 0.4s ease`.

**Scrollama offset:** `0.1` on mobile (`matchMedia('(max-width: 800px)')`), `0.5` on desktop. Low mobile offset prevents fire-never when step cards fill full viewport height.

### Mobile Layout (≤800px) — CORRECTED

The mobile sticky behavior has two distinct modes:

**Chart sections (S2, S3, S5+S6):** `.sticky-col` remains `position: sticky; top: 0; height: 50dvh; width: 100%`. Chart stays pinned at top of viewport while step cards scroll beneath it. `overflow: hidden` on sticky container. `border-right: none; border-bottom: 1px solid var(--border)`.

**S1 (text-only, no chart):** `[data-section="s1"] .sticky-col` overrides to `position: relative; height: auto` — no sticky. The display text scrolls naturally with the page. This avoids a fixed/sticky text block on mobile which would pin non-interactive copy uselessly.

**S4 (no scrolly, no sticky):** Not a `.scrolly` section. Uses `padding: var(--space-2xl) var(--space-lg)` on mobile (override from `--space-page` desktop). Stats grid collapses to 1 column (`grid-template-columns: 1fr`).

**Steps column (all sections, mobile):** `width: 100%; padding: 0 1.5rem`.

**Pip indicator (mobile):** `display: none` — hidden on all mobile breakpoints.

### S1 — Hook (single scroll step, no chart)

- Sticky panel: large display text block — `.s1-display` (two-line heading). No chart component.
- Step card: single `data-step="0"` card. Contains a `<ul class="news-links">` of 3–5 `<li>` items, each an `<a class="news-link">` link.
- News links style: `color: var(--text); text-decoration: underline; text-decoration-color: var(--border); text-underline-offset: 3px`. Hover: `text-decoration-color: var(--gold)`. Transition: 150ms.
- Each `<li>` has `padding: var(--space-sm) 0`. Each `.news-link` has `display: inline-block; min-height: 44px; padding: var(--space-sm) 0` — guarantees 44px touch target (MOB-03).
- Links open in new tab: `target="_blank" rel="noopener noreferrer"`.
- No pip indicator for S1 (single step — pip row not rendered).
- S1 sticky is NOT sticky on mobile — overridden to `position: relative; height: auto`.

- Source citation: `.source-link` element below step card body. JetBrains Mono 0.7rem, `color: var(--muted)`, underline with `text-decoration-color: var(--border)`. Hover: `color: var(--text)`. `display: inline-block; margin-top: var(--space-md); min-height: 44px; padding: 8px 0`. Opens in new tab.

## Isometric Coin Stack — Visual Specification (S2 and S3)

Custom SVG illustration pattern for `DeficitChart.svelte` and `GDPChart.svelte`.

**Coin unit:** Each individual coin is an isometric ellipse — `rx: stackWidth/2`, `ry: stackWidth/6` (standard 3:1 isometric ratio). Stack width: 64px desktop / 44px mobile (≤480px).

**Coin color:** Top face: `rgba(201,168,76,0.85)` (near `--gold`). Edge face: `rgba(201,168,76,0.45)`. Coin edge height: 8px per layer. SVG `fill` attributes using rgba derivations of `--gold` — no new CSS tokens.

**Stack height mapping:** Each Rp 1 trillion = 2px visual height (capped at 200px desktop / 140px mobile). Labels show exact IDR figure in trillions.

**Negative value (S3 Q1 2025 −3.24%):** Inverted stack below baseline. Fill `rgba(196,66,66,0.6)`. Label reads "−3.24%" in `color: var(--red)`.

**Active/inactive state:** Active stack: full opacity, `transform: scaleY(1.02)` on outermost SVG group (0.3s ease). Inactive: `opacity: 0.4`.

**Period label:** Below each stack. JetBrains Mono 10px, `rgba(237,232,220,0.35)`.

**Value label:** Above each stack (or to the right for deficit). JetBrains Mono 11px, `rgba(237,232,220,0.7)`. Format: "Rp 309 T" or "+10,93%".

**Baseline rule:** 1px horizontal `<line>` across chart width. Stroke `var(--border)`.

## Interaction Contracts

### Scrollama Multi-Section Architecture

Phase 2 extends the single-scroller pattern from Phase 1 to one Scrollama instance per section.

- Each scrolly section (S1, S2, S3, S5+S6) uses its own `scrollama()` instance.
- Each instance targets `[data-section="N"] [data-step]` scoped to that section's container.
- `offset: 0.1` on mobile (matchMedia ≤800px), `offset: 0.5` on desktop.
- Scroller setup runs inside `requestAnimationFrame` (Phase 1 WR-03 fix).
- `onDestroy` destroys all scroller instances and removes resize listeners.
- Resize handler calls `.resize()` on every active scroller.

### D3 Re-sort Transition (S6)

- Trigger: `activeStepS5` reaches the S6 step index (index 2 in the shared S5+S6 section).
- Action: `InstitutionsChart.svelte` internal `$derived` detects step change. D3 selection on all `<g class="bar-group">` elements. `transition().duration(600).ease(d3.easeCubicInOut)` applied to `transform: translateY(...)` recalculated from high-pagu sort order.
- Non-flagged opacity: `transition().duration(400)` from `opacity: 1` → `opacity: 0.2`.
- Reverse: User scrolls back to S5 steps — bars re-sort to total-pagu order with identical transition.

### News Article Links (S1)

- `<a>` elements: `target="_blank" rel="noopener noreferrer"`.
- No JavaScript click handlers — plain anchor navigation.
- Underline: `text-decoration: underline; text-decoration-color: var(--border); text-underline-offset: 3px`. Hover: `text-decoration-color: var(--gold)`. Transition: 150ms.
- Touch target: `display: inline-block; min-height: 44px; padding: var(--space-sm) 0` on the `<a>` element (MOB-03).

### Source Citation Links (S2, S3)

- `.source-link` element placed below step card body text.
- `display: inline-block; margin-top: var(--space-md); min-height: 44px; padding: 8px 0`.
- JetBrains Mono 0.7rem, `color: var(--muted)`, underline with `text-decoration-color: var(--border)`. Hover: `color: var(--text)`. Transition: `color 0.15s ease`.
- Opens in new tab. No icon. Text only.

### Language Toggle (inherited from Phase 1 — no changes)

- No changes to the Phase 1 language toggle contract.
- All S1–S6 i18n keys react to `lang` state prop-drilled from `App.svelte` into all chart components.
- Toggle: fixed top-right, `min-width: 44px; min-height: 44px`, JetBrains Mono 11px, color `--gold`.
