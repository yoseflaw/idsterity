## Phase Goal

**As a** site visitor who has just absorbed the deficit, institutions, and anchor-count narrative, **I want to** see the top keywords from AI-flagged procurement packages, filter the cloud by government tier or specific institution, and click any keyword to see the actual procurement packages behind it, **so that** the abstract irony resolves into concrete, investigable records I can scrutinize myself.

<objective>
Deliver the S8 word-cloud + S9 record-table overlay vertical slice as a complete, click-driven, bilingual feature. The slice spans two layers (data was prepared in Plan 02): (1) copy — add 11 S8 and 11 S9 bilingual keys to `i18n.js`; (2) interactive UI — add the S8 `<section>` to `App.svelte` with one scrollama step, a filter bar, a flex-wrap word cloud, an institution search dropdown, and an S9 record-table overlay that replaces the cloud inside S8's sticky panel when a word is clicked.

Purpose: SEC-08 + SEC-09 + MOB-02 + MOB-03 — completing the emotional arc from irony to discovery. S8 surfaces the keywords; S9 lets the user inspect the records.

Output: A scrollable, click-driven S8 section in the dev server. Filter toggles re-load different word clouds. Clicking a word reveals the records overlay. Closing the overlay returns the cloud. On <480px the cloud degrades to a horizontal-scroll chip strip.

This plan depends on Plan 01 (S7 wiring in App.svelte and i18n.js must be merged first to avoid file conflicts) AND Plan 02 (the per-word JSON files must exist for S9 to fetch).
</objective>
