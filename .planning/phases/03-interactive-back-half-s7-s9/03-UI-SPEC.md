## Typography

All CSS token values inherited from Phase 1. Consolidated to the same 4-token scale used in Phase 2. No new tokens.

| Token | CSS Variable | Size | Font | Weight | Line Height | Phase 3 Roles |
|-------|-------------|------|------|--------|-------------|---------------|
| Micro | `--text-micro` | 0.7rem | JetBrains Mono | 400 | 1.5 | S7 eyebrow label, anchor unit price citation line, S8 eyebrow label, filter toggle label, institution search placeholder, S9 table header label, table pagu column (monospace values), S9 record count badge, word-cloud transition note ("institution filter applies to cloud only") |
| Body | `--text-body` | 0.9rem | Source Serif 4 | 400 | 1.72 | S7 step card prose, S8 step card prose, S9 table cell text (lembaga, satker, paket, inappropriateReason), institution search input text |
| Heading | `--text-heading` | 1.4rem | Libre Baskerville | 700 | 1.2 | S7 step card h3, S8 section heading ("Apa yang mereka cari?") |
| Display | `--text-display` | `clamp(2.2rem, 5vw, 3.8rem)` | Libre Baskerville | 700 | 1.08 | S7 anchor count-up figure (the large animating number in the sticky panel) |

**S7 anchor figures:** The animated count-up number renders at `--text-display`, weight 700, Libre Baskerville, color `var(--gold)`, line-height 1.08. The anchor label (e.g. "cangkir kopi jago" / "cups of kopi jago") renders at `--text-body`, color `var(--muted)`. Citation line renders at `--text-micro`, color `var(--muted)`.

**S7 transition label:** "Atau, lebih seriusnya…" / "Or, on a more serious note…" renders at `--text-micro`, JetBrains Mono, `color: var(--muted)`, `font-style: italic`. Same pattern as `s6TransitionLabel` in Phase 2. Shown with `aria-live="polite"` when Step 1 fires.

**Word cloud button font-size scaling:** Word cloud `<button>` elements do NOT use one of the 4 CSS token sizes — font-size is computed inline per word based on count. Computed per word as: `font-size: clamp(0.75rem, {countRatio}rem, 2.2rem)`. Count range from `wordcloud-all.json`: min 855, max 6144. Mapping: count 855 → 0.75rem, count 6144 → 2.0rem (linear interpolation, clamped). This is an inline computed style on each `<button>` element and is NOT a CSS token entry — it does not count toward the 4-token limit. Word label text uses Source Serif 4 (matching body font) at the computed size.

**S9 table pagu column:** Renders in JetBrains Mono `--text-micro` (0.7rem), `color: var(--text)`. Right-aligned within the cell. Format: "Rp X,X M" (millions) or "Rp X,X B" (billions) — abbreviated for table readability.

## Section Layout Contracts

### S7 — Anchor Count-Up (two scroll steps)

**Section type:** Scrolly (sticky + steps), same two-column structure as S2/S3/S5.

**Sticky panel:** Contains the anchor visualizations. Two beats displayed sequentially per step.

**Step 0 — absurd beat (kopi + seblak):**
- Sticky panel shows two anchor items stacked vertically.
- Each item: count-up number at `--text-display` in `var(--gold)`, label at `--text-body` in `var(--muted)`, citation line at `--text-micro` in `var(--muted)`.
- Both items animate simultaneously when Step 0 fires.
- Layout: `.s7-anchor-pair` — flex column, `gap: var(--space-xl)`.

**Step 1 — sobering beat (SD schools + puskesmas):**
- `s7TransitionLabel` ("Atau, lebih seriusnya…") appears first with `aria-live="polite"` — `--text-micro`, italic, `color: var(--muted)`.
- After 300ms delay (CSS transition), SD school item fades in, then puskesmas item fades in 150ms after.
- Count-up figures render in `var(--red)` (not gold) — civic loss signal.
- Same layout structure as Step 0.

**Count-up animation spec:**
- Duration: 1.8 seconds.
- Easing: ease-out cubic (`cubic-bezier(0.33, 1, 0.68, 1)`).
- Counter starts at 0 (or 10% of final value on mobile to reduce frame budget). Increments via `requestAnimationFrame`.
- Step 0 items start simultaneously on Step 0 enter.
- Step 1 items: transition label visible at 0ms, SD count-up starts at 300ms, puskesmas count-up starts at 450ms.
- Number format: Indonesian locale — periods as thousands separator (e.g. "2.145.844.908"). English locale — commas as thousands separator (e.g. "2,145,844,908").

**Mobile (≤800px):** `.sticky-col` is `position: sticky; top: 0; height: 50dvh` — same as chart sections in Phase 2. Anchor pairs reflow to fit 50dvh. Font size of count-up figures scales from `clamp(2.2rem, 5vw, 3.8rem)` — same `--text-display` token; the clamp handles small screen sizes.

**S7 does NOT need its own Svelte component** (Claude's discretion — D-04): anchor animation state and count-up logic are simple enough to be authored inline in `App.svelte`, co-located with `activeStepS7` state. If the count-up RAF loop exceeds ~30 lines, extract to a `countUp(target, duration, cb)` utility function within `App.svelte`.

## Interaction Contracts

### S7 Count-Up Animation

- Fires on Scrollama `onStepEnter` for S7 steps.
- Step 0: both count-up animations start simultaneously via `requestAnimationFrame`.
- Step 1: transition label becomes visible at step enter (CSS class toggle), count-up for SD starts after 300ms (`setTimeout`), count-up for puskesmas starts after 450ms.
- Stepping backwards (user scrolls up): count values reset to 0. Count-up re-fires on re-entry.
- `prefersReducedMotion`: if `window.matchMedia('(prefers-reduced-motion: reduce)').matches`, skip animation and display final value immediately. No RAF loop.

### S8 Filter Interactions

- **Central / District / All toggle:** Clicking a toggle button sets `activeFilter` state (`'all'` | `'central'` | `'district'`). Word cloud re-renders with the new JSON. If `selectedWord` is set, close the overlay and reset `selectedWord = null` (cloud view returns, then user clicks word again under new filter).
- **Institution picker:** User types in the input → native JS array filter on `wordcloud-lembaga.json` keys → dropdown shows matching institution names. User clicks a name → `activeFilter = 'lembaga'`, `activeLembaga = selected_name` → cloud loads from `wordcloud-lembaga.json[activeLembaga]`. If `selectedWord` is set, close overlay first.
- **Reset button:** Sets `activeFilter = 'all'`, `activeLembaga = null`, clears search input value, reloads `wordcloud-all.json` cloud. `selectedWord = null`.
- **Mutually exclusive:** activating institution picker clears the Central/District toggle to the "Semua" state. Clicking Central/District clears the institution input.

### S9 Table Toggle

- **Open:** Click on any `.s8-word` button → `selectedWord = word`. Cloud hidden via `{#if !selectedWord}`, table shown via `{#if selectedWord}`. Svelte reactive update — no animation. Fetch fires immediately.
- **Close (× button):** `selectedWord = null`. Cloud returns.
- **Close (outside click):** `on:click` listener on `.s8-sticky-panel` with `if (!event.target.closest('.s9-overlay')) { selectedWord = null }`.
- **Toggle off (same word):** If user somehow triggers the selected word again (edge case — cloud hidden while overlay shows, so this only happens programmatically), `selectedWord = null`.

### Scrollama S7/S8

- `makeScroller('s7', i => { activeStepS7 = i })` — 2 steps.
- `makeScroller('s8', i => { activeStepS8 = i })` — 1 step (reveal trigger).
- Both follow the established pattern: `offset: 0.1` mobile, `offset: 0.5` desktop.
- Added to `scrollers` array in `onMount`; destroyed in `onDestroy` automatically.
