# v1.1 Feedback — Design Spec

**Date:** 2026-05-16
**Source:** `feedbacks/v1.1/FEEDBACK.md` + mobile observations
**Status:** Approved, pending implementation plan

---

## Scope

A patch release addressing 12 user-reported issues plus 7 mobile-specific observations. Focus areas: bilingual removal, mobile readability, sticky-scroll behavior, podium redesigns for top-lembaga sections, word-cloud rebuild, and data-pipeline corrections.

Out of scope: new features beyond what is listed, copy rewrites unrelated to TW→Q terminology, dataset re-analysis.

---

## Section 1 — Global Changes

### 1.1 Remove i18n
- Delete `dashboard/src/i18n.js`.
- Remove `lang` state and the flag toggle UI in `App.svelte`.
- Collapse all `{lang === 'id' ? a : b}` ternaries to the `id` branch.
- Inline all Indonesian strings directly into Svelte templates.

### 1.2 Period terminology
- Replace `TW I, TW II, TW III, TW IV` with `Q1, Q2, Q3, Q4` site-wide.
- Full-year strings become `FY 2025`, `FY 2026`.

### 1.3 Sticky-scroll z-order rule
- Sticky chart container sits **above** the scrolling text track.
- Scrolling text passes **behind** the chart.
- Remove all `backdrop-filter`, `filter: blur()`, and overlay opacity hacks from sticky chart containers.
- Applies to S5, S6, S7, S8, S9 on mobile (and desktop where the same overlay was used).

### 1.4 Headline / title wrap
- Add `max-width` and `text-wrap: balance` to all `h1`/section headings.
- Default to two-line layouts on mobile; remove `white-space: nowrap` anywhere it forces overflow.

## Section 2 — Per-Section Fixes

### 2.1 S3 — Deficit by quarter (item 3, item 5)
- **Investigation first:** confirm bar height mapping uses correct yScale domain.
- Convert to **line chart**: single line across Q1 2025 → Q1 2026, dot markers at each quarter.
- Color encoding: green stroke + marker for the saving quarter (negative deficit), red for spending quarters.
- Reduced transparency on line/markers (clarity over beauty).
- Larger data labels above each marker.

### 2.2 S4 — APBN bars not matching values (observation B)
- Investigation item: bar heights visually inverted vs. their Rp values in `error2.png`.
- Fix bar height to be strictly proportional to value via `yScale(value)`.

### 2.3 S5 — Top 3 podium by pagu (item 7)
- Replace top-5 horizontal bar chart with a 3-block podium component.
- **Layout:** 1st in center (tallest), 2nd on viewer's left (medium), 3rd on viewer's right (shortest). Fixed heights, not data-scaled.
- **Above each block:** medal icon + abbreviated lembaga name (via `LEMBAGA_ABBR` map).
- **Inside each block:** large mono Rp pagu value.
- **Below podium:** "Juara Harapan" caption listing ranks 4 and 5 as `Name — Rp X T  ·  Name — Rp Y T`.

### 2.4 S6, S7 — Sticky-scroll cleanup
- Apply global z-order rule from §1.3.
- No new logic; remove blur/overlay only.

### 2.5 S8 — Reverse podium by high+absurd pagu (item 10)
- Starts as a continuation of the S5 podium (same lembaga, same heights).
- **Scroll-driven morph:** blocks flip downward, color transitions to red gradient (deepest red for 1st, fading for 2nd/3rd).
- **Final state:** 1st place sits deepest below baseline at center, 2nd shallower on left, 3rd shallowest on right.
- **Inside each block:** two stacked labels — count of high+absurd packages (headline) and total flagged pagu (secondary).
- **Below:** "Juara Harapan" line for ranks 4–5 of the *flagged-pagu* list.
- **Data source:** new `lembaga-flagged-totals.json` (see §3.1).

### 2.6 S9 — Kopi Jago / Seblak (item 11)
- Apply §1.3 (text behind giant numbers, no blur).
- Investigation: animation start trigger fires too late on scroll-in; fix during execution.

## Section 3 — Data Pipeline Changes

### 3.1 New output: `lembaga-flagged-totals.json`
- Top-30 lembaga ranked by `highPagu + absurdPagu` descending.
- Same schema as `lembaga-totals.json`.
- Emitted by `prepare-data.py`.

### 3.2 Stop-word expansion (word cloud) — two-layer
**Layer 1 — build-time stop list (`word-cloud.py`):**
- Hardcoded list applied during tokenization; excluded words are never counted or emitted.
- Initial list (lemma form):
  ```
  sewa, operasional, biaya, dinas, luar, eselon, satker, pimpin,
  pengadaan, jasa, barang, belanja, kegiatan, pelaksanaan,
  penyediaan, pengelolaan, paket, layanan, dukungan, kantor
  ```
- Confirm tokenizer already lemmatizes; if not, ensure stop words match surface forms emitted.
- Regenerate `wordcloud-{all,central,district}.json` + all `word-*.json` shards.

**Layer 2 — runtime exclusion override (`dashboard/public/data/stop-words-overrides.json`):**
- Plain JSON array of additional words to hide, e.g. `["aplikasi", "rapat"]`.
- Loaded by `WordCloud.svelte` at runtime; matching chips are filtered out of the rendered cloud.
- No data-pipeline rerun required — edit JSON, refresh page.
- Empty `[]` by default. Committed alongside data files.
- Matching is case-insensitive, exact-word (no partial matches).

### 3.3 Verification — labeling correctness
- Confirmed during brainstorming: `prepare-data.py` aggregation is correct (Kemhan: highCount 669, absurdCount 185 matches nemesis.assai.id reference).
- The "only Kota Medan looks red" issue is a *visual* problem (flagged pagu is tiny relative to total pagu for large-budget lembaga), not a data error.
- Total-pagu encoding stays unchanged on S5–S7 bars; the S8 reverse podium resolves the visibility problem by re-ranking on flagged pagu via §3.1.

## Section 4 — New / Changed Components

### 4.1 New components
- **`Podium.svelte`** — fixed-height 3-block podium. Props: `data` (top-3 array). Renders medals, abbreviated names, Rp labels, Juara Harapan caption. Used in S5.
- **`ReversePodium.svelte`** — morphing inverted podium. Props: `data` (top-3 from flagged list), `scrollProgress` (0–1 morph driver). Used in S8.
- **`Modal.svelte`** — lightweight full-screen overlay with close button. Mobile-only usage (desktop renders content inline).
- **`WordPaketCards.svelte`** — card-list renderer; one card per paket. Card layout: line 1 = Lembaga, line 2 = Paket name, line 3 = Rp pagu + Label badge. Used in both modal (mobile) and inline (desktop) contexts.

### 4.2 Modified components
- **`InstitutionsChart.svelte`** — top-5 bar chart removed from S5. Either delete entirely or repurpose for S7 explainer view (decide during execution).
- **`WordCloud.svelte`** — full-width container, chip-grid layout (2–3 columns), chip font-size scales with frequency. Filter row above gets horizontal-scroll fade affordance on the right edge.
- **`App.svelte`** — wire Podium → S5, ReversePodium → S8, full-screen Modal → word cloud on mobile, scroll-progress signal from S8 sticky to ReversePodium.
- **`DeficitChart.svelte`** — bar chart → line chart.

### 4.3 New helper module
- **`dashboard/src/lembagaAbbreviations.js`** — static map of full lembaga name → abbreviation. Seeded with Kemhan, PUPR, Kemenkes, Kementan, DKI Jakarta, and extended as needed for any lembaga that lands in the top-30 of either ranking.

## Section 5 — Word Cloud Interaction

- **Filter row** (`Semua / Pemerintah Pusat / Pemerintah Daerah`) stays above the cloud. Scroll affordance on right edge for mobile.
- **Chip grid:** 2–3 columns of pill-shaped chips, font-size scales with word frequency. Order is grid-deterministic.
- **Tap chip:**
  - Chip glows (border + tint, matches existing pill selected state).
  - **Mobile:** opens full-screen `Modal` containing heading `Paket dengan kata "{word}"` and a scrollable `WordPaketCards` list (top 3).
  - **Desktop:** renders `WordPaketCards` list (top 3) inline below the cloud.
- The "Kata kunci bermasalah" side panel is removed.

## Acceptance Criteria

- [ ] No English strings rendered anywhere; no language toggle present.
- [ ] All `TW I/II/III/IV` strings replaced with `Q1/Q2/Q3/Q4`; full-year strings show `FY YYYY`.
- [ ] On mobile, no chart container uses blur or backdrop-filter; scrolling text disappears behind sticky chart cleanly.
- [ ] Section titles wrap to ≤2 lines on a 360px viewport without clipping.
- [ ] S3 renders as a line chart with green saving marker and red spending markers.
- [ ] S4 bar heights are strictly proportional to their values.
- [ ] S5 shows a 3-block podium with abbreviated names, Rp labels, and a Juara Harapan caption for ranks 4–5.
- [ ] S8 starts as the S5 podium and morphs into a reverse podium ranked by `highPagu + absurdPagu`, with count + pagu labels and a Juara Harapan caption.
- [ ] `lembaga-flagged-totals.json` exists and contains top-30 by flagged pagu.
- [ ] Word cloud is full-width, uses a chip grid, and the side panel is removed.
- [ ] Tapping a word on mobile opens a full-screen modal with a close button; desktop renders cards inline.
- [ ] Each paket card shows Lembaga, Paket name, Rp pagu, and a Label badge.
- [ ] Build-time stop-word list is applied; words from the agreed list no longer appear in the cloud.
- [ ] Runtime override at `dashboard/public/data/stop-words-overrides.json` filters additional words from the cloud without requiring a data-pipeline rerun.
- [ ] S9 numbers animate from 0 immediately on scroll-in (not halfway through).
