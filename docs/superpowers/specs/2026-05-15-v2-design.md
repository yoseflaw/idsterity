## Phase 1 — Research & Data

Python-side only. Produces corrected data consumed by Phase 2. No visual output.

### 1.1 Add "absurd" as 4th classification tier

**Finding:** Dataset confirmed to have 4 labels: `{'low', 'med', 'high', 'absurd'}`. Current UI and scripts only handle 3.

**`prepare-data.py` changes:**
- Per-institution output in `lembaga-totals.json` gains two new fields: `absurdCount` (int) and `absurdPagu` (int)
- `summary-stats.json` gains `labelCounts.absurd` and `labelPagu.absurd`
- Rerun script to regenerate both JSON files

**`word-cloud.py` changes:**
- Current filter: `isInappropriate != "high"` (skip non-high records)
- New filter: include if `isInappropriate in {"high", "absurd"}` — both tiers are the most egregious and produce the most interesting package names
- Rerun to regenerate all 4 wordcloud JSON files

### 1.2 Word cloud NLP: nouns only, exclude "kantor"

**`word-cloud.py` changes:**
- After tokenization + lemmatization, add POS filtering via `nlp-id` to keep only nouns
- Add `"kantor"` to the explicit exclusion/stopword list
- Rerun to regenerate all 4 wordcloud JSON files

### 1.3 APBN & Gov Spending: re-research correct numbers

**Finding:** User confirmed current numbers in `constants.json` are wrong. Sources are already listed in the file.

**Approach:**
- Fetch the three APBN deficit sources from `kemenkeu.go.id` (oct2024, fy2025, q1_2026)
- Fetch the four GDP government consumption YoY sources from `bps.go.id` (Q1–Q4 2025, Q1 2026)
- Extract correct values and update `constants.json` in place
- Same fields, same structure — corrected numbers only

### 1.4 Critical bug fix: word cloud click returns 0 results

**Root cause:** `App.svelte:112` fetches word records using a relative path:
```js
`data/word-${word}-${filterKey}.json`
```
All other fetches correctly prepend `import.meta.env.BASE_URL`. Since Phase 4 deployed to `/sterity/`, this resolves to `/data/word-...json` (404) instead of `/sterity/data/word-...json`.

**Fix:** Change line 112 to:
```js
import.meta.env.BASE_URL + `data/word-${word}-${filterKey}.json`
```

## Phase 2 — Core UI Redesign

All Svelte/JS changes. Builds on corrected data from Phase 1.

### 2.1 Color system: add "absurd" tier

- New CSS variable: `--absurd: #7a0000` (deep crimson — same red family as `--high`, darker and more saturated)
- Add to legend in S3, S4, S5
- All stacked bar components receive the new color band

### 2.2 S3 & S4: absurd appears in charts

- **S3 (Analysis Results):** "absurd" becomes its own visible slice in the label breakdown visualization
- **S4 (Label Breakdown):** Horizontal stacked bars gain an absurd band per institution
- No layout changes — data + color additions only

### 2.3 S5: full InstitutionsChart redesign

**Three scroll steps** (via existing `step` prop on `InstitutionsChart`):

| Step | Description |
|---|---|
| 0 | Top 5 institutions by total pagu, **monochrome bars**. Medals 🥇🥈🥉 visible on ranks 1–3 from the start. |
| 1 | Same 5 bars, **color bands animate in** showing low/med/high/absurd composition. |
| 2 | **Reorder:** pull top 5 by inappropriate pagu from the full 30. New institutions slide in, old ones out. Medals reassign to new top 3 — this is the punchline. |

**Implementation notes:**
- Chart data sliced to 5 bars (down from 30)
- Step 2 re-sorts the full `lembaga` array (already in memory) by `highPagu + absurdPagu` descending, takes top 5
- Medals are positional (rank 1/2/3 in whichever sort is active), not tied to specific institutions

### 2.4 Hero: remove duplicate stat line

Remove the line "Rp 642.2 T dalam 3.009.760 paket pengadaan." from the hero section. Hero renders two clean headline lines only. The stat is already embedded in the story — no information lost.

### 2.5 Word cloud: auto-select top word on scroll-in

When S8 enters the viewport (via the existing `IntersectionObserver`/scrollama callback), set:
```js
selectedWord = cloudWords[0].word;
```
The S9 table populates immediately with records for the highest-frequency word. User can click any other word to override. The existing `wordCache` handles repeat visits — no extra fetch cost.

### 2.6 i18n: sync English to Indonesian changes

- Read `dashboard/src/i18n.js`
- For every key where the Indonesian (`id`) text was updated but English (`en`) still has old text, update `en` to match the new meaning
- No structural changes — same keys, updated English values only

## Phase 3 — Mobile

Mobile-only fixes. Desktop behavior unchanged throughout.

### 3.1 Text overlay: blur + darken chart behind active step

**When active scroll step changes on mobile:**
- Sticky chart receives CSS class `chart--dimmed`
- Class applies: `filter: blur(3px) brightness(0.35)` with a CSS transition
- Text panel floats over with `background: rgba(13,17,23,0.5)`

**Implementation:**
- Add `chart--dimmed` class binding that fires when any text step is active over the sticky chart — exact condition determined by inspecting `activeStepS*` state during implementation
- Class only applies at the mobile breakpoint already defined in `App.svelte` (inspect existing `@media` rules)
- Desktop: no change

### 3.2 Seblak not showing on mobile

- Inspect the seblak comparison card in S7 at mobile viewport width
- Identify the CSS rule causing it to be hidden (likely `display: none` or `overflow: hidden` on a parent)
- Fix the rule so seblak renders consistently with other anchor comparisons (kopi, SD, etc.)

### 3.3 Word cloud mobile layout fix

Two sub-fixes:
1. The single-column word list (mobile fallback) must be scrollable and correctly sized within the viewport — fix the broken layout
2. The auto-select from Phase 2 (§2.5) applies on mobile too — top word auto-fires on scroll-in so S9 is never empty regardless of cloud interaction

## Design Decisions Log

| Decision | Choice | Rationale |
|---|---|---|
| "absurd" label | Keep as "absurd" | User's explicit instruction |
| "absurd" color | Deep crimson `#7a0000` | Coherent escalation within red family |
| S5 reorder | Reveals new top 5 from full 30 | The surprise swap is the punchline |
| Mobile overlay | Blur + darken chart | Cinematic depth-of-field, chart stays "present" |
| Word cloud default | Auto-select top word on scroll-in | S9 never empty, no UX failure mode |
| Work structure | 3 phases by concern | Clean dependencies, natural checkpoints |
