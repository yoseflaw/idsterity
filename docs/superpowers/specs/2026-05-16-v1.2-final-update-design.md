# v1.2 Final Update — Design Spec

**Date:** 2026-05-16
**Source feedback:** `feedbacks/v1.2/FEEDBACK.md`
**Style reference:** `feedbacks/v1.2/STYLING.md`, `feedbacks/v1.2/idsterity-tokens.css`

## Scope

Two-phase update to the live idsterity site (https://yosef.id/sterity/):

1. **Phase B-1 — Styling foundation.** Replace the current dark-mode palette/typography with the light-mode editorial system from STYLING.md (cream paper, EB Garamond + IBM Plex, crimson/terracotta accents).
2. **Phase B-2 — Content fixes.** Twelve scoped content/behavior tweaks across Bagian 1–8.

Phase B-1 lands first so Phase B-2 fixes apply to already-correct visuals.

## Phase B-1 · Styling foundation

### Goal

Bring the site visually onto the yosef.id-derived design system defined in `feedbacks/v1.2/STYLING.md`. Visual refresh only — no architectural rewrite of `App.svelte` section structure.

### Tasks

1. **Token install.** Copy `feedbacks/v1.2/idsterity-tokens.css` to `dashboard/src/lib/styles/idsterity-tokens.css`. Import it once near the top of `App.svelte` (or via `main.js`) so tokens are available to every component.
2. **Font swap.** In `dashboard/index.html`:
   - Remove Google Fonts links for Libre Baskerville, Source Serif 4, JetBrains Mono.
   - Add Google Fonts links for EB Garamond (400, 400i, 700, 700i), IBM Plex Sans (500), IBM Plex Mono (400, 400i).
3. **Global resets.** Replace current global CSS with the §11 STYLING.md snippet: cream `--bg-base` body, serif default, dotted-underline links, `font-feature-settings: 'liga','kern','onum'` on body.
4. **Color audit.** Every hard-coded hex in `.svelte` files gets replaced with a token reference (`var(--…)`). Charts read `--viz-*` tokens. Crimson `--accent` for accent italic spans in headings. Terracotta `--accent-soft` for eyebrows, stat numbers, selected chip background.
5. **Component styles.** Update where conventions diverge:
   - Section eyebrow → sans, uppercase, `--accent-soft`, tracking per `--tracking-meta`.
   - Two-tone headings → main `--ink-1` italic + accent `--accent` italic.
   - Sidebar narration card → `--bg-sunken` background, `1px solid --rule`, sticky on desktop, stacks on mobile.
   - Risk badge → bordered pill with `--viz-red` foreground + `--viz-red-bg`.
   - Filter tabs / tag pills → see STYLING.md §5.9.
6. **Constraints (per STYLING.md §9):**
   - No pure white background; no pure black ink.
   - No box-shadow, no gradients, no border-radius > 2px on cards (pills/badges use `--radius-pill`).
   - No animation beyond opacity fades ≤400ms and number count-ups.

### Out of scope (B-1)

- Re-architecting components into the suggested `lib/components/` directory tree (STYLING.md §10 is aspirational; current single-file layout stays).
- Adding new sections — that happens in B-2 (Bagian 8).
