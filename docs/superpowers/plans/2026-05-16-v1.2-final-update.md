> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply the v1.2 final-update spec — light-mode editorial restyle plus 12 scoped content fixes — to the idsterity site, ready to redeploy under `/sterity/`.

**Architecture:** Two-phase update. Phase B-1 first lays down the design tokens, swaps fonts, and migrates every Svelte component's hardcoded colors to `var(--…)` tokens (no structural rewrite). Phase B-2 then makes 12 content/behavior edits and adds a new closing Bagian 8 "Bagikan" section. Final task is a build + LinkedIn share preview check.

**Tech Stack:** Svelte 5 (runes), Vite 5, d3, scrollama; static JSON data; @fontsource packages for fonts (replacing Libre Baskerville / Source Serif 4 / JetBrains Mono with EB Garamond / IBM Plex Sans / IBM Plex Mono). No test framework exists in the project; verification is via `npm run dev` browser checks plus `npm run build`.

### Task 4: Migrate `App.svelte` colors and typography to tokens

**Files:**

Read `dashboard/src/App.svelte`. Build a mental list of:

- every `font-family` declaration,
- every `font-size` literal (px/rem) on headings, eyebrows, body, captions.

- [ ] **Step 2: Replace surface, ink, and rule references**

For each hex value, map to the closest token from STYLING.md §2:
- backgrounds (cream / panel / sunken) → `--bg-base` / `--bg-raised` / `--bg-sunken`
- primary text → `--ink-1`, body → `--ink-2`, captions → `--ink-3`
- accent crimson italics → `--accent` (use sparingly: hero accent phrase, section title accent phrase)
- eyebrows and stat-number emphasis → `--accent-soft` (terracotta)
- borders/hairlines → `--rule` (primary) or `--rule-soft` (subtle)

- [ ] **Step 3: Replace typography**

- All headings: `font-family: var(--serif)` (italic, weight 400 unless explicitly bold per STYLING.md §3 type scale).
- Section eyebrows (`BAGIAN N:` labels): `font-family: var(--sans); text-transform: uppercase; letter-spacing: var(--tracking-meta); color: var(--accent-soft); font-weight: 500; font-size: var(--size-meta);`
- Body prose: `font-family: var(--serif); font-size: var(--size-body); color: var(--ink-2); line-height: var(--lh-body);`
- Source/caption/meta lines and any number labels: `font-family: var(--mono); font-size: var(--size-mono); color: var(--ink-3);`
- Sidebar narration card: `background: var(--bg-sunken); border: 1px solid var(--rule); border-radius: var(--radius-card); padding: var(--space-6) var(--space-5);`

- [ ] **Step 4: Two-tone heading pattern**

Convert section titles to the two-tone pattern from STYLING.md §3:

```svelte
<h1 class="section-title">
  <span class="title-main">…main phrase…</span>
  <span class="title-accent">…accent phrase…</span>
</h1>

<style>
  .section-title { font-family: var(--serif); font-size: var(--size-h1); font-weight: 400; line-height: var(--lh-snug); letter-spacing: var(--tracking-display); }
  .title-main { color: var(--ink-1); font-style: italic; }
  .title-accent { color: var(--accent); font-style: italic; }
```

Apply at minimum to the Hero and Bagian 1 titles. Other section titles may stay single-color if no accent phrase warrants crimson.

### Task 16: Item 10 — Bagian 7 top-3 selection logic

**Files:**
- Modify: `dashboard/src/WordPaketCards.svelte`

- [ ] **Step 1: Locate the selection logic**

- [ ] **Step 2: Implement the new selection**

Replace the current derivation with this exact logic:

```js
function selectTop3(rows) {
  // 1. Dedupe by paket name — keep highest pagu per name.
  const byName = new Map();
  for (const r of rows) {
    const cur = byName.get(r.paket);
    if (!cur || r.pagu > cur.pagu) byName.set(r.paket, r);
  }
  const distinct = [...byName.values()];

  // 2. Reserve a slot for the highest-pagu "absurd" if any exist.
  const absurd = distinct
    .filter(r => isAbsurd(r))
    .sort((a, b) => b.pagu - a.pagu);
  const high = distinct
    .filter(r => isHigh(r) && !(absurd[0] && r.paket === absurd[0].paket))
    .sort((a, b) => b.pagu - a.pagu);

  const picks = absurd[0]
    ? [absurd[0], ...high.slice(0, 2)]
    : high.slice(0, 3);

  // 3. Sort final 3 by pagu descending for display order.
  return picks.sort((a, b) => b.pagu - a.pagu);
}
```

`isAbsurd(r)` and `isHigh(r)` must match how the data tags absurd/high — verify by inspecting one row in the data file or via a `console.log` of the first row. Likely `r.tags?.isInappropriate === 'high'` plus a separate "absurd" indicator (check existing code for the absurd predicate; reuse it).

Wire this into the `$derived` block: `let topCards = $derived(selectTop3(rawRows));`
